# Li, S. et al. (2024), Buildings 14, 3322 -- FIGURE 9 DIGITISED
# Moment-deflection response at midspan, eight post-tensioned scaled T-beams.
# https://doi.org/10.3390/buildings14103322  (CC BY)
#
# Companion to Li2024_corroded_pc_beam.txt, which carries the tables. This
# file carries the CURVES, which the tables do not: the shape of the response
# and the deflection at which each beam failed.
#
# HOW. Each panel is one black curve with square markers on a GREEN dashed
# grid, so colour separates the data from its own calibration -- the grid sits
# at x = 5,10,...,30 mm and M = 10,...,60 kN m. The page is rendered at
# 600 dpi, the eight panels are found from the grid blobs themselves, ink is
# anything clearly off the white page and not green, and the value read at
# each pixel column is the MIDDLE of the ink run (its top edge is half a
# marker high -- about 1.1 kN m -- and reading that puts every curve high).
#
# THE CHECK, and it is an independent one: the peak of each digitised curve
# against the flexural capacity in Table 2, which was NOT used anywhere in the
# calibration.
#
#   beam   rho%   digitised   Table 2    error
#   A0     0.01      61.78     61.63   +0.25%
#   A1     0.33      61.89     61.71   +0.29%
#   A2     1.24      59.89     59.93   -0.07%
#   A3     2.37      56.88     56.70   +0.32%
#   A4     4.52      53.93     53.72   +0.39%
#   A5     6.15      49.08     49.39   -0.63%
#   A6     7.47      47.91     47.86   +0.10%
#   A7     8.31      44.16     44.54   -0.84%
#
# All eight inside 0.9%. The x axis needs no such check -- it is the grid.
#
# THE TERMINAL DROP is the last row of each block. Every beam ends with a
# near-vertical fall, which section 3.1 of the paper attributes to the steel
# wires rupturing. The deflection at which it happens is the beam's ULTIMATE
# DEFLECTION, and it is not in any table:
#
#   beam    rho%   drop at (mm)   M before -> after (kN m)
#   A0      0.01        34.24       61.78 ->  47.00
#   A1      0.33        33.69       61.89 ->  44.25
#   A2      1.24        31.59       59.89 ->  43.28
#   A3      2.37        28.92       56.88 ->  42.90
#   A4      4.52        25.32       53.93 ->  41.26
#   A5      6.15        22.74       49.08 ->  39.51
#   A6      7.47        19.88       47.91 ->  34.50
#   A7      8.31        16.50       44.16 ->  31.90
#
#   -- 34.2 mm down to 16.5 mm over 8.3% of mass loss. That column is what a
#      corrosion model has to reproduce and it cannot be fitted to a table.
#      But it lives on the DEFLECTION axis, so use the RATIOS (A7/A0 = 0.48)
#      and not the millimetres -- see the block above.
#
# DEFLECTION IS MEASURED FROM THE START OF LOADING (one dial gauge at
# midspan), so it already excludes the camber -- directly comparable to a
# model's deflection measured from the state after prestress transfer.
# Convert to total applied load with P = M / 0.425 (shear span 850 mm).
#
# --------------------------------------------------------------------------- #
#  THE MOMENT AXIS IS SOUND. THE DEFLECTION AXIS CARRIES ABOUT 1.4 mm THAT
#  IS NOT THE BEAM -- read this before using the x values.
# --------------------------------------------------------------------------- #
#  The uncracked section has no free parameters: the transformed EI of A0's
#  midspan section is 6.695 MN m2, which under this four-point rig is
#  19.25 kN m of moment per mm of midspan deflection. The paper's own
#  cracking moment is "approximately 22 kN m". At M = 22 the beam is by
#  definition still uncracked, and it should therefore be at
#
#      1.14 mm   by hand from the transformed section
#      1.06 mm   from the model (cases/case_31), which agrees with it
#
#  The digitised curve is at 2.44 mm. The difference, 1.38 mm, is present
#  BEFORE the beam cracks, where neither tension stiffening, bond-slip nor
#  any constitutive choice can reach it. All eight curves show it: their
#  1-2 mm slopes are 4.8 to 8.8 kN m/mm against the 19.25 the section
#  requires, and corrosion cannot be the reason (8% of strand area moves the
#  uncracked EI by under 2%). It is the rig -- support seating, the
#  distribution beam bedding in, or a gauge reading actuator travel.
#
#  As a series compliance that is k = 15.9 kN m/mm. Removing it -- calibrated
#  on that ONE point and on nothing from any model -- puts A0 within 1.2 mm
#  of cases/case_31 over the whole ascending branch, to 95% of capacity:
#
#      M kN m     25     30     40     45     50    58.5
#      raw      2.93   4.51   6.85   8.23  11.24   17.78
#      minus M/k  1.36   2.63   4.34   5.41   8.11   14.11
#      model    1.28   1.89   4.01   5.64   7.41   12.88
#
#  SO: use the MOMENT axis freely -- it is checked to 0.9% against Table 2
#  below. Use the deflection axis only RELATIVELY, beam against beam, where
#  a common rig compliance largely cancels. Do not compare a model's
#  deflection to a raw x value, and do not fit a constitutive parameter to
#  the early shape of these curves: 1.4 mm of it is the testing machine.
#
# THE FIRST MILLIMETRE IS NOT RELIABLE. The elastic branch rises about
# 11 kN m per mm, so it crosses a whole pixel column in one step and the
# column's midpoint over-reads it (A0 comes out at 12.4 kN m where the
# authors' first marker is nearer 8.5). The origin is prepended because a
# beam under no load has no deflection; everything below 1 mm is that
# interpolation, not a reading. Use points at 2 mm and beyond.
#
# Curves are resampled every 0.5 mm from the origin. Columns:
#   beam   deflection[mm]   moment[kN.m]
#
