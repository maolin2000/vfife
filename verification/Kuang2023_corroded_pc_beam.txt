# Kuang, Y. et al. (2023), "Experimental Study on the Flexural Behavior of
# Corroded Prestressed Concrete Box Girders", Applied Sciences 13, 8396.
# https://doi.org/10.3390/app13148396   (open access, CC BY)
#
# Six 1:15.68 scaled T-beams of a 32.6 m high-speed-railway PC box girder, L1
# to L6, post-tensioned with ONE 1x7-15.2-1860 strand in a grouted phi 50
# bellows, the strand corroded by impressed current, then broken in four-point
# bending. Digitised from Tables 1, 3 and 4 and Figure 2 of the PDF with
# `pdftotext -layout`; used by cases/case_30_kuang_control_beam.yaml.
#
# ---------------------------------------------------------------------------
# READ THIS BEFORE USING THE ULTIMATE LOADS: THEY ARE NOT USABLE.
# ---------------------------------------------------------------------------
# The reported ultimate loads violate section equilibrium. The beam's steel is
# one strand and two phi 8 bars at the soffit, so
#
#     T_max = 140 mm2 x 1872 MPa + 101 mm2 x 430.4 MPa = 305.4 kN
#
# and the beam is 250 mm deep, so no internal lever arm can exceed 0.250 m:
#
#     M_u <= 305.4 kN x 0.250 m = 76.34 kN m      (an unreachable ceiling --
#     compression resultant on the top surface, tension resultant on the
#     soffit, every bar at its ULTIMATE strength simultaneously)
#
# Table 4 reports 76.14 kN m for the uncorroded L1: 99.7% of that ceiling, a
# lever arm of 249.4 mm on a 250 mm beam. Corroborating rather than rescuing:
#
#   * the authors' OWN section analysis in the same table gives 49.43 kN m --
#     35% below their own measurement -- and the paper does not remark on it;
#   * an independent fibre model (case_30) gives 54.59 kN m;
#   * L1's reported failure mode is concrete crushing (CC), which means the
#     strand did NOT reach f_pu, so the true capacity is below the ceiling.
#
# The CRACKING loads are consistent and are used: measured M_cr 23.58 kN m
# against the authors' predicted 23.06 (2.3%), and 23.58 / 72.0 = 0.3275 m
# recovers the shear span a/2, so the lever arm is confirmed by the same data.
# The DEFLECTIONS are consistent too. It is the load SCALE alone that does not
# close, which is why this is read as a measurement problem rather than a
# geometry one. Li et al. (2024) -- Li2024_corroded_pc_beam.txt -- is the
# campaign whose capacities do close, and carries that check instead.
# ---------------------------------------------------------------------------
#

#   overhang each end         95        web, midspan            90
